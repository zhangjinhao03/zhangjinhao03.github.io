1.2 做 DP 题的四步

做任何 DP 题，都按这四步走：

  1. 定义状态：dp[i] / dp[i][j]表示什么？
  2. 写状态转移：dp[i] 如何由更小状态推出来？
  3. 初始化：最小规模问题的答案是什么？
  4. 确定遍历顺序：先算谁，后算谁？

其中最重要的是第一步：

状态定义错了，后面全错。
状态定义对了，转移通常就自然出来了。
